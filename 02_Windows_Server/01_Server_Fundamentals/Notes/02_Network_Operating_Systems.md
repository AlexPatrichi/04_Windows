# Network Operating Systems (NOS)

**University:** Solent University  
**Course:** Network Applications  

## Overview

A **Network Operating System (NOS)** is an operating system that supports communication, resource sharing and centralised management across a network.

Its main responsibilities include:
- Managing network users and computers.
- Providing access to shared files and resources.
- Authenticating users and controlling permissions.
- Hosting and managing network services.
- Supporting network administration and security.

Examples include:
- Microsoft Windows Server.
- Linux server operating systems.

## Windows Server

**Windows Server** provides administrative technologies such as:

- **Active Directory Domain Services (AD DS):** Centralised management of domain users, groups and computers, including authentication.
- **Group Policy:** Centralised configuration and enforcement of settings for users and computers.
- **Distributed File System (DFS):** Technologies for organising shared folders and replicating data between servers.
- **PowerShell:** A command-line shell and scripting environment for administration and automation.

These technologies help administrators manage large numbers of users and computers efficiently.
